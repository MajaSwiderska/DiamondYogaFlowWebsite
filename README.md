# 🧘‍♀️ Diamond Yoga Flow Website

## ✨ Project Overview

This project is a modern, calming website created for **Diamond Yoga Flow**, a women-owned community wellness studio focused on yoga, relaxation, and nervous system regulation.

The website serves as an online home for the studio where visitors can:

* Learn about the instructor
* Understand what happens during a class
* View the weekly schedule
* Contact the studio or join the community online

The design emphasizes **simplicity, calmness, and accessibility**, reflecting the peaceful environment of the yoga studio itself.

---

## 🌿 Website Sections

### 🏠 Hero Section

The homepage welcomes visitors with a large visual banner and the message **“Find Your Balance.”**
An inspirational quote introduces the philosophy of the studio and invites visitors to begin their wellness journey.

---

### 👩‍🏫 About the Instructor

This section introduces **Aga (Agnieszka)**, the founder of Diamond Yoga Flow.

Her studio was created to help people manage stress, reconnect with their bodies, and improve their mental well-being through mindful movement and sound therapy.

The goal is to create a **safe and welcoming environment** for people of all experience levels.

---

### 🌸 What You Experience in Class

This section highlights the different elements included in a typical class:

* 🧘‍♀️ **Yoga Flow** – Build strength, flexibility, and balance
* 🌬️ **Breathwork** – Calm the nervous system and reduce stress
* 🤸 **Deep Stretching** – Release tension and improve mobility
* 🧠 **Guided Relaxation** – Reset the mind and body
* 🔔 **Japanese Orin Sound Therapy** – Deep relaxation through sound vibrations

The section uses animated icons and styled cards to create an engaging and interactive experience.

---

### 📅 Class Schedule

Visitors can easily view the **weekly class schedule** displayed visually so they can quickly see available days and times.

Social media links include:

## 💻 Technologies Used

This website was built using modern front-end technologies:

* **HTML5** – Website structure
* **CSS3** – Styling and layout
* **Flexbox** – Responsive page layout
* **Google Fonts** – Playfair Display & Lato for typography
* **AOS (Animate On Scroll)** – Smooth scroll animations

---

## 🎨 Design Philosophy

The design of this website reflects the calming environment of a yoga studio by focusing on:

* Soft colors and natural tones
* Clean, readable typography
* Balanced spacing and layout
* Simple navigation for easy browsing
* Gentle animations for a modern feel

The goal is to create a **welcoming and peaceful digital space** for visitors.
