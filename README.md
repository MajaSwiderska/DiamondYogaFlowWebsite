# Diamond Yoga Flow Website

This project is a simple, responsive website built for a yoga business.
It showcases the instructor, class schedule, and ways for clients to connect through social media or phone.

## Features

* Modern homepage with a hero image and slogan
* About section introducing the instructor
* Class schedule displayed as an image
* Social media links (Instagram, TikTok, etc.)
* Clickable phone number for easy contact
* Instructor photo in the About section
* Custom logo in the header
* Professional Google Fonts styling
* Mobile-friendly layout

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts

## How to Run the Website

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Right click the file and select **Open with Live Server** (recommended) or open it directly in a web browser.

## Customization

You can easily update the website by editing the following files:

* `index.html` – page structure and content
* `style.css` – styling, colors, layout
* `script.js` – interactive features
* images – replace with your own logo, instructor photo, and schedule
